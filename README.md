# Runrail for Homebrew

```sh
brew install TechDev009/runrail/runrail
```

installs the `runrail` command line ([TechDev009/runrail](https://github.com/TechDev009/runrail)), and

```sh
brew install --cask TechDev009/runrail/runrail
```

installs Runrail Desktop ([TechDev009/runrail-desktop](https://github.com/TechDev009/runrail-desktop)).

`Formula/runrail.rb` and `Casks/runrail.rb` are written by each project's publish workflow when a
release is published, from that release's `SHA256SUMS.txt`. Changes made here by hand are replaced
at the next release; open issues in the project repositories.
